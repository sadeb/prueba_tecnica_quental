# Entrega

- Repositorio Git accesible con el **historial de commits completo**.
- **README** con instrucciones de instalación y ejecución de backend, frontend e infraestructura, y una **breve explicación de las decisiones de diseño**.
- El proyecto debe poder levantarse con **docker-compose** siguiendo el README, incluyendo PostgreSQL, Neo4j y Kafka.
- Tras la entrega: **entrevista técnica** de revisión de código y de las decisiones. El uso de IA es legítimo; la entrevista confirma la comprensión del trabajo.
