# Requisito 4 · API propia y funcionalidad de usuario

1. **Documentación OpenAPI** que refleje correctamente endpoints: parámetros, filtros, respuestas y códigos de estado.
2. **Registro e inicio de sesión** de usuarios.
3. **Favoritos** por usuario autenticado: añadir, listar y eliminar (referencia a Character).
4. **Consulta de datos sincronizados**: listado con filtros y paginación, detalle, y la consulta de relaciones resuelta sobre el grafo.
5. **Respuestas y códigos de estado coherentes**; **formato de error homogéneo** para toda la API.
